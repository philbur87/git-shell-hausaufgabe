# Git Shell Hausaufgabe

Dieses Repository enthält ein kleines Bash-Skript für einfache IT-Support-Aufgaben.

Das Skript ermöglicht:
- Eingabe eines Benutzernamens
- Anzeige eines einfachen Support-Menüs
- Anzeige von Systeminformationen
- Prüfung des Speicherplatzes
- Verarbeitung ungültiger Menüauswahlen

## Geübte Git-Themen

- git add
- git commit
- git push
- git branch
- git checkout
- git merge
